🚀 Getting Started

  1. Create a table: Use CREATE TABLE to make a new table
  2. Insert data: Use INSERT INTO to add rows
  3. Query data: Use SELECT to view your data
  4. Upload files: Import SQL files (max 20MB)

💡 Tips for Beginners:

  • SQL statements end with a semicolon (;)
  • Keywords like SELECT, FROM are not case-sensitive
  • Use single quotes for text values: 'text'
  • Click any example command to try it!

📝 Common Commands

Creating Tables:

CREATE TABLE students ( id SERIAL PRIMARY KEY, name VARCHAR(100), age INTEGER, grade DECIMAL(3,2) );

Inserting Data:

INSERT INTO students (name, age, grade) VALUES ('Alice', 15, 95.5);

Selecting Data:

SELECT * FROM students;
SELECT name, grade FROM students WHERE age > 14;

Creating Indexes:

CREATE INDEX idx_student_name ON students(name);

Updating Data:

UPDATE students SET grade = 98.0 WHERE name = 'Alice';

Deleting Data:

DELETE FROM students WHERE age < 14;

Joining Tables:

SELECT students.name, courses.title FROM students JOIN enrollments ON students.id = enrollments.student_id JOIN courses ON enrollments.course_id = courses.id;
